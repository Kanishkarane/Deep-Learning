## Overview

An end-to-end study of recurrent sequence models in three parts:

1. **Sequence classification (UCI HAR):** Vanilla RNN vs LSTM vs GRU on raw smartphone inertial signals (`N × 128 × 9`), with training curves, confusion matrices, a sequence-length study (T = 32, 64, 128) and the numerical BPTT exercise.
2. **Video understanding (UCF101 subset):** frozen MobileNetV2 features (`10 × 1280` per video) followed by an LSTM/GRU.
3. **Sequence-to-sequence:** an encoder–decoder LSTM trained on a synthetic reversal task with teacher forcing.

The notebook also contains the seven additional exercises (units, GRU vs LSTM, stacked layers, BiLSTM, sequence length vs cost, video LSTM vs GRU, seq2seq with different output length).

## How to run

**Recommended: Google Colab (GPU).**

1. Upload the notebook to Colab and set `Runtime → Change runtime type → T4 GPU`.
2. Run all cells from top to bottom. The datasets are downloaded automatically.
3. First do a smoke test with `QUICK_TEST = True` in the config cell (a few minutes). Then set it back to `False` for the real run (roughly 35–50 minutes on a T4).

**Locally:**

```bash
pip install -r requirements.txt
jupyter notebook Experiment_6_RNN_LSTM_GRU.ipynb
```

A GPU is strongly recommended.

## Datasets

| Dataset | Use | Notes |
|---|---|---|
| [UCI HAR Using Smartphones](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones) | Sequence classification | Raw inertial signals, 6 activities. Subset of 400 windows per class (2400 total), split 70/15/15 |
| [UCF101](https://www.crcv.ucf.edu/data/UCF101.php) | Video understanding | 4 classes: Basketball, Biking, TennisSwing, WalkingWithDog. Split by clip group (g01–g04 test, g05–g07 validation, g08–g25 train) |

Datasets are not included in this repository. The video source can be changed with `VIDEO_SOURCE` (`"official"`, `"huggingface"` or `"manual"`); the official UCF101 archive is about 6.5 GB.

## Results (our run)

**UCI HAR test set (360 windows, macro-averaged):**

| Model | Accuracy (%) | F1 (%) | Parameters | Training time (s) |
|---|---|---|---|---|
| RNN | 84.17 | 84.23 | 1,974 | 24.43 |
| LSTM | 93.06 | 93.02 | 6,006 | 22.85 |
| GRU | 95.56 | 95.54 | 4,758 | 20.28 |

**Video (48 test videos):** CNN–LSTM 85.42% accuracy (selected on validation), CNN–GRU 91.67%.  
**Seq2seq reversal (985 test sequences):** 100% token accuracy and 100% sequence accuracy.

Results come from single runs on a Colab GPU. Small differences between models (about 1–2 points) can be run-to-run variation, and training times vary between runs.

## Notes

- Normalisation statistics are computed from the training set only, and the test set is used only for the final evaluation.
- UCI HAR windows overlap by 50%, so a random split gives slightly optimistic accuracy compared with a subject-wise split.
- MobileNetV2 is frozen and used only as a feature extractor.
