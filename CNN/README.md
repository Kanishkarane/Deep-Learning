CNN on CIFAR-10 — Experiment 3

Overview

This experiment implements and studies a Convolutional Neural Network (CNN) for image classification using the CIFAR-10 dataset.

The notebook covers:

Loading and preprocessing CIFAR-10.

Visualizing sample images and class distribution.

Studying the effect of convolution kernel sizes (3×3, 5×5, 7×7).

Studying stride and padding combinations.

Visualizing feature maps from the first convolution layer.

Comparing Max Pooling and Average Pooling.

Training a CNN for 20 epochs and plotting training/validation accuracy and loss.

Evaluating the model using accuracy, precision, recall, F1-score, and a confusion matrix.

Reporting the total number of trainable parameters.

Dataset

The experiment uses the CIFAR-10 dataset provided through tensorflow.keras.datasets.

CIFAR-10 contains:

50,000 training images

10,000 test images

Image size: 32 × 32 pixels

3 colour channels (RGB)

10 classes:

airplane

automobile

bird

cat

deer

dog

frog

horse

ship

truck

The notebook normalizes pixel values from [0, 255] to [0, 1].

3 × 3 kernel

7 × 7 kernel

Stride and Padding Study

A 3 × 3 convolution is tested with:

Stride 1 + valid padding

Stride 2 + valid padding
